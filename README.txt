# LEV – Main Menu Prototype

مشروع واجهة القائمة الرئيسية للعبة ليف، يعمل كصفحة ويب.

## التشغيل
1. فك ضغط ملف `LEV-Menu.zip`.
2. افتح `index.html` في متصفح حديث.
3. الأفضل رفع محتويات المجلد إلى GitHub Pages حتى تعمل الصفحة كرابط.

## نظام زر «متابعة»
- الزر مخفي افتراضيًا.
- لا يظهر إلا عند وجود تقدم محفوظ في `localStorage`.
- حفظ التقدم يتم لاحقًا من كود مرحلة اللعب عبر:
  `window.LEV.saveProgress({ checkpoint: "المطبخ" })`
- حذف الحفظ عبر:
  `window.LEV.clearSave()`

مهم: زر «العب» و«متابعة» حاليًا يعرضان نوافذ توضيحية لأن مراحل اللعب الفعلية لم تُبنَ بعد. لا يتم إنشاء تقدم وهمي.

## الملفات
- `index.html`: هيكل القائمة.
- `style.css`: التصميم والمؤثرات.
- `game.js`: التفاعلات والإعدادات ونظام الحفظ المبدئي.
- `assets/background.png`: خلفية القائمة.
